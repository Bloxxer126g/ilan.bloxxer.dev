    What the checks cover
    • Checked: CPU and motherboard socket, memory generation, memory slots and maximum capacity, motherboard size against case size, and PSU wattage against a rough draw estimate.
    • Not checked: cooler socket support, graphics card length against the case, M.2 and SATA port counts, PSU cables, BIOS support for newer CPUs.
    • CPU sockets, memory generation for some boards and graphics card power are worked out from names and model families, because the source data does not list them. Boards sold in both DDR4 and DDR5 versions are flagged so you can confirm.
    • The power estimate is CPU TDP plus graphics card board power plus 100 W for everything else. Use it as a floor.
    Part data: docyx/pc-part-dataset (MIT licence), scraped from PCPartPicker. Prices are USD snapshots.
